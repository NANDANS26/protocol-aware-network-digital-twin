## Reporting a Vulnerability

We prioritize the security and integrity of the Protocol-Aware Network Digital Twin platform. If you discover a security vulnerability, we appreciate your help in disclosing it responsibly.

### How to Report
Please report security vulnerabilities by creating a confidential security advisory on GitHub or by contacting the core systems security maintainers via the platform's designated security issue intake channel.

Please include:
1. A clear description of the vulnerability.
2. Steps to reproduce or proof-of-concept demonstration.
3. Potential impact on the host system or network digital twin state.
4. Suggested remediation if available.

### Safe Harbor & Responsible Disclosure
- We ask researchers to allow a reasonable disclosure window (typically 90 days) before public discussion.
- Testing should only be conducted against simulated environments, PCAP files, or network segments you explicitly own or have written authorization to audit.
- Do **not** attempt denial of service against production networks or exfiltrate sensitive data.
